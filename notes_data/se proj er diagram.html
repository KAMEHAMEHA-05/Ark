ER Diagram Description

Entities and Attributes:

  1. Resident

    • Resid

    • Email

    • Phone

    • Locality

  2. Worker

    • WorkerID (Primary Key)

    • Name

    • Email

    • Phone

    • Skills (Array or separate Skill entity)

  3. Administrator

    • AdminID (Primary Key)

    • Name

    • Email

    • Phone

  4. Issue Ticket

    • TicketID (Primary Key)

    • Title

    • Description

    • Category

    • Priority (Enum: Critical, High, Medium, Low)

    • Status (Enum: New, In Progress, Resolved, Escalated)

    • Location

    • CreatedAt (Timestamp)

    • AssignedAt (Timestamp)

    • ResolvedAt (Timestamp)

  5. Assignment

    • AssignmentID (Primary Key)

    • TicketID (Foreign Key)

    • WorkerID (Foreign Key)

    • AssignedAt (Timestamp)

    • Status (Enum: Assigned, In Progress, Completed)

  6. Feedback

    • FeedbackID (Primary Key)

    • TicketID (Foreign Key)

    • ResidentID (Foreign Key)

    • Comments

    • Rating (Optional)

    • CreatedAt (Timestamp)

Relationships:

  • Resident “creates” Issue Ticket (One-to-Many)

  • Issue Ticket “is assigned to” Worker via Assignment (Many-to-Many through Assignment)

  • Worker “handles” Assignment (One-to-Many)

  • Administrator “oversees” many Issue Tickets and Assignments (One-to-Many)

  • Resident “provides” Feedback on Issue Ticket (One-to-Many)
